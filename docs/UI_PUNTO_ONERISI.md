# Yazı Boyutu İncelemesi

WPF FontSize değerleri 96 DPI mantıksal ekran birimleridir (DIP); tipografik punto karşılığı DIP × 0,75'tir. Windows ekran ölçeği görünür fiziksel boyutu ayrıca artırır.

| Öğe | Önceki DIP | Uygulanan DIP |
|---|---:|---:|
| Genel TextBlock | 18 | 14 |
| Form girişi / açılır kutu / tarih | 17,5 | 14,5 |
| Standart düğme | 16,5 | 14 |
| Sayfa başlığı | 29 | 23 |
| Bölüm / kart başlığı | 19 | 16 |
| Sayfa alt açıklaması | 15 | 13 |
| Alan etiketi | 14 | 12,5 |
| Sol menü etiketi | 13,5 | 12,5 |
| Tablo satırı | 15–16 | 13 |
| Özet tutarları | 21,5–23,5 | 19–20 |
| Ana ekran büyük tutarı / sayaçlar | 42 / 30 | 34 / 25 |

Form alanları 42'den 36 DIP yüksekliğe; standart düğmeler 42'den 34–36 DIP'e; tablo satırları 42–44'ten 34–36 DIP'e indirilebilir. Kart iç boşlukları 24'ten 16–18 DIP'e indirilebilir.

Kullanıcının onayıyla genel küçültme uygulandı. Ana ekranın büyük tutarı 34 DIP, sayaçları 25 DIP; form alanları 36 DIP yüksekliğinde, tablolar 13 DIP yazı ve 36 DIP satır yüksekliğindedir. İki istatistik detay düğmesi 13 DIP yazı / 34 DIP yükseklikle korunmuştur. Ana ekrana vadesi geçen fatura adedi/tutarı ve farklı kurum sayısı kartları eklenmiştir.
